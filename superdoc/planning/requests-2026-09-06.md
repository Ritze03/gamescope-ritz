last loaded (measured: sharpness 10 -> crosshair gap edit -> sharpness 5 again), and the

60 %, crosshair pixels (640,352)/(640,332) red->blue; edit -> B.json only; click CS2 ->

setters mutate the cache without loading it (results.txt names the one-line fix).

## [~] 16. Shaders: Adaptive Brightness needs a mode selection

> Shaders: Adaptive Brightness needs a mode selection: "Whole image" and a very
> dynamic mode (dynamic contrast + brightness + gamma, no blown-out parts), good for
> strong-contrast scenes; originally for dark vs bright CS2 workshop maps, will be
> used in other games (Rust) too.

**Desktop-verified, laptop pending** — `cb01946`, binary `2601d1a028ee`
(sha256 prefix of `build-release/src/gamescope`). Design and every number in
`superdoc/features/shader-effects.md` → "Adaptive Brightness".

- The row is a three-way Choice, `Off | Whole image | Dynamic`, in its own
  "Adaptive Brightness" band (the Six Budget forbids a seventh param, and the Effects
  band's `n / m` count is Switch-only). Same id, same six params, new config key
  `reshade.adaptive_brightness.mode` (additive; old configs resolve to Whole image).
- Dynamic = levels gain (p98 → 0.9 within min/max gain) + gamma landing the median on
  Target (bounded 0.5..1.5, a darkening gamma capped so p2 never drops below
  `p2 × min_gain`) + a Reinhard-shaped shoulder above 0.7 that only engages when the
  curve would exceed 1.0 and maps white exactly onto white. Per channel, encoded
  space, Strength blends with the identity. Maths in `src/shaders/effects_curve.h`,
  compiled by the GLSL pass *and* `tests/test_effects_curve.cpp` from the same text.
- Measured headless (`scripts/effects-regression.sh`, all defaults, strength 1.0;
  captures `build-release/verify-shots/adaptive-2026-09-06/`):

  | Scene / region (input) | Off | Whole image | Dynamic |
  | --- | --- | --- | --- |
  | dark: darkest band (5) | 5 | 10 | **50** |
  | dark: bands 8 / 12 / 16 / 20 | same | 16 / 24 / 32 / 40 | **64 / 78 / 90 / 101** |
  | dark: 240 highlights | 240 | **255 (clipped)** | **253** |
  | dark: pure black | 0 | 0 | **0** |
  | bright: 200 / 215 / 230 bands | same | 115 / 124 / 132 | **165 / 180 / 196** |
  | bright: 245 band | 245 | 141 | **213** |
  | bright: 30 shadows | 30 | 17 | **15** (= 30 × min_gain) |
  | mid: 26 / 77 / 128 / 179 / 230 | same | 26 / 77 / 128 / 178 / 229 | **25 / 75 / 126 / 177 / 228** |
  | dark → bright, 230 band over time | — | — | 252 @0.37 s, 245 @1.29 s, 205 @3.36 s, 196 settled |

  Unit tests: 11 cases / 1.26 M assertions (`[effects_curve]`) — monotonic, output in
  [0, 1], black → black, identity at strength 0, shoulder continuity, config
  round-trip. Regression gate: 8 PASS, 0 FAIL.
- Not done: the laptop check (no sync, per the brief); no GPU-timestamp measurement of
